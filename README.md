# 로컬 LLM 구동 계산기 v3.1

> **"우리 업무 PC에서 인터넷 없이 돌아가는 AI(로컬 LLM)를 쓸 수 있을까?"** 를 대략 알아보는 계산기입니다.
> 내 PC의 그래픽카드·메모리 사양을 고르면, 어떤 모델이 돌아가는지와 **대략의 응답 속도**를 추정해서 보여 줍니다.

**`index.html` 파일을 더블클릭하면 됩니다.** 설치도, 로그인도, 인터넷도 필요 없습니다. (`calc.js`, `app.js`와 같은 폴더에 두세요.)

---

## 1. 이럴 때 쓰세요

- 업무용 노트북·PC로 로컬 AI를 써 보려는데, **내 PC 사양으로 되는지 모르겠을 때**
- 기관에 로컬 AI 도입을 건의하려는데, **필요한 PC 사양을 대략 어림잡고 싶을 때**
- "이 모델은 메모리가 얼마나 필요한가요?"를 **표로 한눈에** 보고 싶을 때

> 이 도구는 AI를 직접 돌려 보지 않습니다. **계산으로 어림잡은 값(추정치)** 만 보여 줍니다. 결정 전에 실제로 한 번 돌려 보세요.

## 2. 사용법 (1분)

1. 이 폴더의 **`index.html`을 엽니다.**
2. 기본값은 **일반 업무용 노트북(내장그래픽, RAM 16GB)** 입니다. 다른 PC라면 **그래픽카드**와 **시스템 메모리(RAM)** 를 고르세요.
3. 표에서 **초록(원활) / 노랑(느림) / 빨강(구동 불가)** 으로 모델별 판정을 봅니다. 맨 위 카드에 이 설정의 추천 모델이 나옵니다.
4. 목록에 없는 새 모델은 **"목록에 없는 모델 크기(B)"** 칸에 크기만 넣으면 같은 방식으로 계산해 줍니다. (예: 4.5B 모델이면 `4.5`)
5. 모델 이름이나 그 아래 **"공식 페이지 ↗"** 를 누르면 개발사가 공개한 모델 소개 페이지(Hugging Face)가, **"Ollama 페이지 ↗"** 를 누르면 Ollama 모델 페이지가 새 탭으로 열립니다. 이 링크를 누를 때만 인터넷을 씁니다.
6. 모델을 직접 내려받아 쓰려면 표의 **[복사]** 버튼으로 명령을 복사해 Ollama(ollama.com)에서 실행합니다. 모델 내려받기에는 인터넷이 필요합니다. 계산기 자체는 필요 없습니다.

### 입력값 쉬운 설명
| 항목 | 뜻 | 비유 |
|---|---|---|
| VRAM | 그래픽카드 전용 메모리 | 작업대 크기. 모델이 작업대에 다 올라가야 빠르게 돌아갑니다. |
| 메모리 대역폭 | 메모리가 데이터를 읽는 속도 | 도로 폭. 넓을수록 한 번에 많이 나릅니다. **속도를 거의 이 값이 정합니다.** |
| 문맥 길이 | AI가 한 번에 기억하는 대화·문서 분량 | 길수록 메모리를 더 씁니다. |
| 양자화 | 모델을 압축하는 정도 | 4-bit가 가장 흔합니다. 많이 압축하면 작아지지만 품질이 떨어질 수 있습니다. |
| 모델에 쓸 수 있는 RAM 비율 | 내장그래픽 PC는 RAM을 같이 쓰므로, 다른 프로그램이 쓰는 몫을 뺀 값 | 업무 중에는 50% 정도로 봅니다. |

## 3. 숫자는 어떻게 계산하나

AI가 글자(토큰) 하나를 만들 때마다 모델 전체를 메모리에서 한 번씩 읽습니다. 그래서

```
초당 토큰 수(t/s)  ≈  메모리 대역폭 × 효율  ÷  모델이 차지하는 메모리(GB)
```

- **모델이 차지하는 메모리** = 모델 크기(B) × 압축 계수 + 문맥 메모리(KV 캐시, 단순 근사)
- **효율**: 내장그래픽/CPU **0.20**(아래 실측으로 맞춤), 외장 GPU **0.68**(실측 없음, 참고값)
- 외장 GPU에 다 안 들어가면 일부를 RAM에 둡니다. 이때는 토큰 하나당 걸리는 **시간을 GPU 몫과 RAM 몫으로 나눠 더해서** 계산합니다.
- 아주 작은 모델은 계산상 수백 t/s가 나오지만, 실제로는 다른 오버헤드가 한계가 되므로 **상한 150 t/s**를 둡니다(경험적 값, 실측 없음).
- 전기요금은 "최대 전력을 1시간 계속 쓴 경우의 **상한**"이고, 단가는 직접 바꿀 수 있습니다.

### 실측으로 맞춘 부분 (내장그래픽 노트북)
측정: 12세대 Core i5(U 시리즈) · 내장그래픽 · RAM 약 16GB 노트북, Ollama의 `eval_count ÷ eval_duration`, 120토큰 생성 1회.

| 모델 | 실측 | 계산기 추정 |
|---|---|---|
| gemma:2b (약 2.5B) | 7.0 t/s | 약 6 t/s |
| qwen3.5:2b (약 2B) | 6.5 t/s | 약 7~8 t/s |

수정 전(v2.2) 효율 계수(0.45)로는 같은 PC에서 **약 14 t/s로 실측의 2배**가 나왔습니다. 그래서 0.20으로 낮췄습니다. 스스로 재 보려면 터미널에서 `ollama run 모델이름 --verbose`를 실행해 마지막의 `eval rate`를 보세요.

## 4. 한계 (꼭 읽어 주세요)

- **추정치입니다.** 측정한 PC가 1대, 모델이 2개뿐이라 **실제 속도와 최대 2배쯤 다를 수 있습니다.** 큰 모델(7B 이상)의 속도는 실측하지 않았습니다.
- **외장 GPU(NVIDIA·AMD·Mac) 쪽 속도는 실측하지 않았습니다.** 효율 0.68은 참고값입니다.
- **모델 목록은 2025년 상반기 세대**(Llama 3.x, Qwen 2.5, Gemma 2, DeepSeek-R1 증류, EXAONE 3.5)입니다. 그 뒤에 나온 모델은 크기를 직접 입력해서 쓰세요.
- 문맥 메모리(KV 캐시)는 모델 구조를 따지지 않은 단순 근사입니다. 실제는 ±수십 % 다를 수 있습니다.
- 그래픽카드 사양(VRAM·대역폭·전력)은 제조사 공개값을 옮긴 것이라 오차가 있을 수 있으니, 정확한 값은 제조사 자료를 확인하세요.
- "쾌적/원활" 판정은 속도만 본 것이며 **답변 품질은 평가하지 않습니다.**
- 브라우저가 알려 주는 그래픽 장치 이름(맨 위 칸)은 참고용입니다. 정확한 사양이 아닙니다.

## 5. 개인정보·보안

- **인터넷에 아무것도 보내지 않습니다.** 외부 서버 접속, 분석, 광고가 없고, 글꼴·스타일도 파일 안에 들어 있습니다.
- 입력한 값은 저장하지 않습니다. "결과 링크 공유"는 입력값을 주소에 담아 **클립보드에 복사만** 합니다.

## 6. 파일 구성과 검증 (개발자용)

| 파일 | 역할 |
|---|---|
| `index.html` | 화면. 필요한 스타일을 파일 안에 내장 |
| `calc.js` | 계산 로직(모델 목록, 메모리·속도 추정) |
| `app.js` | 화면 동작 |
| `test_calc.js` | 계산 로직 시험 11개 |
| `test_offline.js` | 외부 주소·네트워크 호출이 없는지 시험 4개 |

```
node test_calc.js
node test_offline.js
```
(Node.js가 있으면 외부 패키지 없이 실행됩니다.) 화면 모양은 인터넷을 끊은 브라우저에서 직접 열어 확인했습니다. 스타일을 다시 만들려면 Tailwind CSS 3의 CLI로 `index.html`을 검사해 필요한 부분만 내장하면 됩니다.

## 7. 윈도우 프로그램(exe)으로 만들기 (선택)

`app.py`는 이 계산기를 일반 프로그램 창으로 띄우는 얇은 껍데기입니다(pywebview). 저장소에는 exe를 넣지 않으며 직접 만듭니다.

```
pip install pywebview pyinstaller
pyinstaller --noconfirm --onefile --windowed --name LocalLLMCalculator ^
  --add-data "index.html;." --add-data "calc.js;." --add-data "app.js;." app.py
```
결과는 `dist\LocalLLMCalculator.exe`입니다. exe도 인터넷 없이 동작합니다(화면 엔진은 윈도우에 기본 있는 Edge WebView2).
